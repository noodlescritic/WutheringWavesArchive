# ▾Constant System Requirements Baseline

* **Android Minimum**: Android 7.0+, Snapdragon 835 / MediaTek G71/72, 4 GB RAM.
* **iOS Minimum**: iOS 14+, iPhone 11 / A13 Bionic iPad, 4 GB RAM.
* **PC Minimum**: Windows 10 64-bit, Intel i5 (9th Gen) / Ryzen 2700, GTX 1060 / RX 570 / Intel Arc A380, 16 GB RAM.
* **PC Recommended**: Windows 10 64-bit, Intel i7 (9th Gen) / Ryzen 3700, RTX 2060 / RX 5700 XT / Intel Arc A750, 16 GB RAM.
