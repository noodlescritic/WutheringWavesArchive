# Known Issues

- In the current version, on mobile devices, switching trial Resonators or exiting certain gameplay modes in the Huanglong - Mengzhou region may result in longer-than-normal loading times. If you encounter this issue, please wait patiently for loading to finish. We will continue optimizing this in future updates.
- In the current version, on mobile devices, some scene cloth effects display abnormally in the Huanglong - Mengzhou region. We will fix this in a future update.
- In the current version, there is a chance that environment models such as vegetation display abnormally in the Huanglong - Mengzhou region. We will fix this in a future update.
- In the current version, water effects display abnormally in a specific area of Huanglong - Mengzhou - Western Fang Peaks, preventing swimming in that body of water. We will fix this in a future update.
- In the current version, on iOS/Mac devices, there is a chance that Persona Pinballs fail to deal damage to enemies during the Star Bouncing event. We will fix this in a future update. Please stay tuned to future announcements.
- In the current version, on Xbox devices, some environment models in the Huanglong - Mengzhou area may be missing or display abnormally. We are currently investigating this issue. Please stay tuned to future announcements.
- In the current version, on Xbox PC devices, after adjusting "Graphics" > "Basic" > "Graphics Quality" in-game and then reopening the settings page, "Graphics Quality" incorrectly displays as "Custom." This is a display-only issue and does not affect the actual graphics preset applied. We will fix this in a future update.
