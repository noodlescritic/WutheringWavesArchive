# Version 3.7 "[Prism's Illusion, Heart's Illumination"

# >>>Known Issues<<<

- In the current version, some environment models in certain parts of the "Huanglong - Mengzhou" area may become blurry on iOS/Android devices. This issue will be resolved in a future update. Please stay tuned for official announcements.
- In the current version, when using the item "Cloudview Seat" in Co-op Mode, interacting with the item may cause clipping or some other issue. This issue will be resolved in a future update. Please stay tuned for official announcements.
- In the current version, the character loading speed may become abnormal when 3D display mode is used. We will continue to refine this feature in future versions and resolve this issue. Please stay tuned for official announcements.
- On PCs equipped with NVIDIA graphics cards, using old driver versions may cause stuttering, slower loading when switching Resonators, or stuttering during the first battle after launching the game. If you encounter these issues and your current NVIDIA graphics driver is older than Version 595.71, we recommend updating your driver to the latest available version. If the issues persist, please contact us via the in-game Feedback feature
