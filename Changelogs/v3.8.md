# Version 3.8: Lilies in a Dying Dream.

# >>>Known Issues<<<

- In the current version, the environment assets may flicker on some Mac devices when the Main Quest "A Bouquet for Tomorrow" progresses to the point of "Train of Souls: Farewell Performance." This issue will be resolved in a future version update. Please stay tuned for official announcements.
- In the current version, display compatibility issues may occur when the game is being run on iPhone Duo. We are working to optimize the game's compatibility with this model. Please stay tuned for official announcements.
- On PCs with NVIDIA graphics cards, using older driver versions may cause stuttering, crashes, slower loading when switching Resonators, or stuttering during the first battle after launching the game. If you encounter  these issues and your current NVIDIA graphics driver is olderthan Version 595.71, we recommend updating your driver to the latest available version. If the issues persist, please contact us via the in-game Feedback feature.
