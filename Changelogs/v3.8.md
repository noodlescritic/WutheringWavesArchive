# Version 3.8: Lilies in a Dying Dream.

# >>>Known Issues<<<
- In the current version, the following issues may occur: map environment assets failing to load, game crashes in certain areas, or the loading screen getting stuck during login. We are investigating the causes of these issues. If you encounter any of them, please try Tools > Clear Patches on the login screen. On PC, you may also try Launcher > Repair Game. If the issue persists, please contact Customer Support and provide details of the issue. 
- In the current version, on Android devices equipped with Dimensity 9300+ and with Vulkan disabled, Resonator Lily's character model may flicker after casting Resonance Skill. If you encounter this issue, you can temporarily resolve it by enabling Vulkan via Settings > Graphics. This issue will be resolved in a future version update. Please stay tuned for official announcements. 
- In the current version, Rover's current Preset Echo set may be unexpectedly unequipped. This issue will be resolved in a future version update. Please stay tuned for official announcements.
- In the current version, the environment assets may flicker on some Mac devices when the Main Quest "A Bouquet for Tomorrow" progresses to the point of "Train of Souls: Farewell Performance." This issue will be resolved in a future version update. Please stay tuned for official announcements.
- In the current version, display compatibility issues may occur when the game is being run on iPhone Duo. We are working to optimize the game's compatibility with this model. Please stay tuned for official announcements.
- On PCs with NVIDIA graphics cards, using older driver versions may cause stuttering, crashes, slower loading when switching Resonators, or stuttering during the first battle after launching the game. If you encounter  these issues and your current NVIDIA graphics driver is older than Version 595.71, we recommend updating your driver to the latest available version. If the issues persist, please contact us via the in-game Feedback feature.
