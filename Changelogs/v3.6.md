# >>>Notice About "New Programming Language" Performance Optimization<<<

- We have conducted several rounds of testing for the "New Programming Language" performance optimization and have verified its stability. Starting from 15:00 on 9/9 (UTC+8), this optimization is available to all players across all platforms. 

◦ Platforms currently open for testing: All Platforms 
◦ Expected results: On devices that meet the requirements across all platforms, the game's overall performance and average frame rate will improve to a certain extent. 
◦ Note: This optimization is currently unavailable on the following devices (with these devices, the game client will continue to run in the original programming language, and the gaming experience will not be affected):

1. iOS mobile devices with any of the following configurations:
  1. RAM ≤ 4GB;
  2.  iPhone 14 series with iOS 16.0/17.0/17.1/17.2.
2. Android mobile devices with the following configuration:
  1. RAM ≤ 6GB.

◦ Test eligibility guide: The version number in the top right corner of the login screen or the time displayed in the bottom left corner of the in-game screen is marked with "\*".

※To join the performance optimization testing for "New Programming Language" on iOS and Xbox Series X|S, you'll need to update to the latest version of the game client. Please update via the corresponding app store.

※If your device meets the requirements, but the version number in the top right corner of the login screen or the time displayed in the bottom left corner of the in-game screen is not marked with "\*", or you encounter any issues during the test, please access the in-game [Feedback] feature to submit your feedback.

We will continue to refine the "New Programming Language" performance optimization based on your feedback. Thank you for your support and understanding!
